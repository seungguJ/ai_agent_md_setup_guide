# Sample Task Document

### 작업명

로그인 실패 메시지 표준화

### 목적

프론트와 백엔드가 서로 다른 실패 문구를 보여 주는 문제를 없앤다.

### 변경 대상 파일

- `frontend/src/features/auth/LoginPage.tsx`
- `frontend/src/features/auth/useAuthSession.ts`
- `backend/src/auth/auth_service.py`

### 구현 요구사항

- 인증 실패 시 사용자에게 보여 주는 기본 문구를 하나로 통일한다.
- 서버 내부 오류와 자격 증명 오류는 코드 레벨에서 구분하되, UI 문구는 요구사항에 맞춘다.

### 금지 사항

- 인증 API 스펙 자체를 변경하지 않는다.
- 세션 저장 방식은 이번 작업 범위에 포함하지 않는다.

### 검증 방법

- 잘못된 비밀번호 입력 시 동일 문구가 노출되는지 확인
- 서버 예외 시 내부 오류 문구가 기존보다 과도하게 노출되지 않는지 확인

### 완료 조건

- 프론트와 백엔드 기준 문구가 일치한다.
- 관련 테스트 또는 수동 검증 결과가 기록된다.

# Sample Project Board

## 목적

이 문서는 현재 작업 상태를 한 곳에서 관리하는 예시다.

## 상태 규칙

- `todo`
- `in_progress`
- `review`
- `done`

## 현재 작업 현황

| ID | 작업명 | 담당 | 상태 | 산출물 | 비고 |
|---|---|---|---|---|---|
| P-101 | 로그인 실패 문구 정리 | Codex | review | 인증 화면, 인증 서비스 | 문구 일치 확인 필요 |
| P-102 | 세션 복구 테스트 추가 | Codex | todo | 테스트 파일 | P-101 이후 진행 |

## 최근 결정

- 인증 API 스펙은 유지하고 UI 문구만 먼저 정리한다.
- 장문 회의 메모는 이 문서에 누적하지 않는다.

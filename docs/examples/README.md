# Examples

이 폴더는 템플릿을 실제로 어떻게 채우는지 보여주는 예시 문서를 모은다.

## 목적

- 빈 템플릿만 보고도 감을 잡기 어려운 문제를 줄인다.
- 실제 프로젝트에 붙일 때 문서 밀도와 표현 수준의 기준을 제공한다.
- 템플릿과 예시를 분리해 템플릿 본문이 불필요하게 길어지는 것을 막는다.

## 포함 예시

- [sample-module.md](sample-module.md)
- [sample-task.md](sample-task.md)
- [sample-project.md](sample-project.md)

## 사용 규칙

- 예시는 복사 시작점이 아니라 참고용이다.
- 실제 프로젝트에 가져갈 때는 템플릿을 복사한 뒤 예시의 밀도와 수준만 참고한다.

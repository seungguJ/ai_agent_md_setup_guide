# Templates Module

## 책임

- 새 프로젝트에 복사할 문서 초안 제공
- GPT 관리자 역할과 Claude 구현 역할의 기준 제공

## 먼저 읽을 파일

- `templates/AGENTS.md`
- `templates/CLAUDE.md`
- `templates/ARCHITECTURE.md`
- `templates/module.md`
- `templates/bootstrap_prompt.md`

## 수정 시 주의

- 템플릿을 추가하거나 삭제하면 `README.md`와 `SETUP_STEPS.md`의 목록을 함께 갱신한다.
- 빈칸만 늘리지 말고 판단 기준을 남긴다.
